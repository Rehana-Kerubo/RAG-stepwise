# POS Device Setup

Before handing over the POS device, confirm the merchant has a valid business permit and a national ID matching the business owner's name on file.

To set up the device, power it on and connect it to the merchant's Wi-Fi or insert a SIM card for mobile data. The device will prompt for a merchant activation code, which is sent to the agent's dashboard once the merchant account is approved.

Enter the activation code on the device screen. The device will sync with the server and download the merchant's profile, including their Till number and business name.

Test the device by running a demo transaction of KES 1. If the transaction goes through and shows on the merchant's dashboard within 2 minutes, the device is correctly configured.

If the device fails to activate, check that the SIM card has active data or the Wi-Fi connection is stable. Restart the device and retry the activation code before escalating to technical support.
