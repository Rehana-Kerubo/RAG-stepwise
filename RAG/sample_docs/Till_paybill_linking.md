# Linking a Till or Paybill Number

Every merchant needs a Till number (for in-person payments) or a Paybill number (for bulk/business payments) linked to their account before they can start receiving payments.

To request a Till number, submit the merchant's business registration certificate and ID through the agent app under "New Merchant > Till Request." Approval typically takes 1-2 business days.

Once approved, the Till number will appear in the merchant's dashboard. Agents must confirm the merchant has received an SMS confirmation before considering the linking complete.

Paybill numbers are only issued to registered businesses with an active KRA PIN. If the merchant does not have a Paybill number, an agent should recommend proceeding with a Till number instead, which has fewer requirements.

If a merchant already has a Till number from a previous provider, it cannot be transferred directly. The merchant must apply for a new Till number under the current system.
